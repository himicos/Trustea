# Track Decision: Walrus vs Agentic Web

## Can Only Submit to ONE Track

---

## Option A: Walrus Track ⭐ RECOMMENDED

### Why It Fits
- Trust documents, amendments, audit trail → **stored on Walrus**
- AI agent memory (decision history, compliance logs) → **MemWal**
- Privacy of trust details → **Seal** (Walrus privacy layer)
- Agent needs persistent, verifiable, long-term memory → **core Walrus value prop**
- Multi-generational trusts running decades = perfect "persistent data" story

### Why It's Strategic
- **$35k 1st** (vs $30k Agentic Web)
- **Lowest competition** historically (Programmable Storage was fewest entries in 2025)
- **Headline sponsor** = Walrus team WANTS to award great projects
- **Wide open scope** — no rigid sub-track requirements
- **Office hours with Abner (Walrus)** for idea validation
- Past winners (SuiSign, WalGraph, SuiMail) = achievable quality bar

### The Pitch to Walrus Judges
"Trustea demonstrates why persistent, verifiable data matters: a family trust that runs for decades needs a data layer that outlasts any single app, server, or company. Walrus is that layer. MemWal gives the AI agent memory across years of trust administration. Seal keeps family financial data private. This is what Walrus was built for."

---

## Option B: Agentic Web Track

### Why It Could Fit
- AI agent that manages trust funds = "autonomous workflow"
- Agent makes financial decisions = "deeply leverages Sui primitives"
- Active DeFi management = uses Deepbook/lending protocols

### Why It's Risky
- 3 sub-tracks have HARD REQUIREMENTS (Risk Guardian, Agent Wallet, Intent Engine)
- Trustea doesn't fit neatly into any of them
- Sub-tracks are "inspiration" but judges will benchmark against them
- "Generic LLM wrappers that happen to hold SUI will not place" — must prove deep Sui integration
- Higher competition (AI = 2nd most popular track in 2025)
- Lower prize ($30k vs $35k)

### Could Work As
- Sub-track 2 (Autonomous Agent Wallet) — agent with capped budget managing trust assets
- But hard requirements include "real Deepbook orders" and "self-enforced budget ceiling" which are tangential to the trust concept

---

## Verdict: WALRUS TRACK

Trustea's core narrative is about **persistent, verifiable, private data for multi-generational wealth management**. The AI agent is the execution layer, but the VALUE is in the data persistence and trust (pun intended) guarantees. That's Walrus.

The Walrus track problem statement literally says:
> "Push toward a future where AI agents are not just reactive tools, but persistent, collaborative systems powered by a reliable data layer."

Trustea IS this. A trust fund agent that persists for decades, powered by Walrus.
