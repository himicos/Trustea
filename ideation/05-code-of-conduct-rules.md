# Code of Conduct — Rules That Affect Strategy

## ⚠️ CRITICAL: Version Control
- **Version control is MANDATORY from day 1**
- "Any repositories with single commits of large files without proper history will be **default assumed to be unqualified** unless proven otherwise"
- **Action**: Init git immediately, commit frequently, meaningful commit messages

## ⚠️ CRITICAL: Pre-existing Work
- No coding/designing before May 7 (official start) — we're past this, we're fine
- Pre-existing code reuse requires:
  1. Written notification to Sui Foundation
  2. Written approval from them
  3. Disclosure in video, description, and during judging
- **BUT: using any pre-existing work (even approved) forfeits the right to be a finalist**
- **Action**: Build everything fresh. Use frameworks/libraries (React, etc.) but no prior project code

## Disqualification Triggers
- Work appearing completed before hackathon
- Work not matching project description/video
- Undisclosed extension of existing work
- **Penalty**: Immediate DQ + full prize revocation + permanent ban from Sui Foundation events

## KYC
- At least 1 team member must pass KYC to receive prizes

## Demo Day
- Team must be online and available July 20-21 (virtual)

## IP
- Team owns all developments
- No rights to third-party APIs/SDKs beyond what's explicitly granted
- Organizers can use project images/recordings in promotional materials
