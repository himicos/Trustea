# Trustea

**On-chain family trust infrastructure on Sui. Programmable rules, AI-managed funds, verifiable data on Walrus.**

Trustea replaces expensive human trustees (1-2% AUM/year) with programmable smart contracts, AI agents, and persistent verifiable storage — making multi-generational wealth management transparent, automated, and 10-100x cheaper.

## How It Works

1. **Create a trust** — define rules in plain language ("Release $50k to Alice at age 25")
2. **Fund it** — deposit assets into the smart contract
3. **Add beneficiaries** — each receives a programmable NFT with their rule set
4. **AI agent manages** — monitors conditions, proposes distributions, actively manages funds in DeFi
5. **Walrus persists** — trust documents, audit trail, and agent memory stored verifiably for decades

## Built With

- **Sui Move** — smart contracts for trust logic, beneficiary NFTs, conditional fund release
- **Walrus / MemWal** — persistent document storage, AI agent long-term memory
- **Seal** — privacy layer for sensitive trust data
- **AI Agents** — condition monitoring, distribution proposals, active yield management
